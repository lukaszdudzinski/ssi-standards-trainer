# Uki's OWI SSI (SSI Standards Trainer)

Aplikacja działa pod adresem: https://lukaszdudzinski.github.io/ssi-standards-trainer/

**Kod jest rozwijany w prywatnym repozytorium `ukis`** (folder `apps/owi-ssi`). To repozytorium służy wyłącznie do publikacji: gałąź `pages` zawiera gotowe pliki aplikacji, które workflow „pages” publikuje na GitHub Pages. Gałąź `main` przechowuje historię kodu sprzed przeniesienia (2026-10).

Nie wprowadzaj zmian w tym repozytorium. Nowe wersje publikuje workflow „Publikuj” w repozytorium `ukis`.
